# 换头像教程

## 一、替换图片文件

把新图片直接覆盖 `public/` 目录下对应文件（文件名必须保持不变）：

| 文件 | 用途 |
|------|------|
| `public/AIIcon.png` | 聊天界面 AI 头像 |
| `public/UserIcon.png` | 聊天界面用户头像 |
| `public/视频来电头像.jpg` | 来电弹窗头像 |
| `public/视频通话背景.jpg` | 来电弹窗背景 |
| `public/视频背景照片.jpg` | 通话中 AI 那侧大图（出现两次）|

图片格式不限，PNG 覆盖 .jpg 也没问题，浏览器按内容识别格式。

---

## 二、修改代码（强制刷新浏览器缓存）

因为 `/public/` 下的文件缓存策略是 `immutable`（7天），换文件后浏览器不会自动更新。需要在引用处把版本号 +1（如 `?v=2` → `?v=3`）。

**`aion-chat/static/chat.js`** 第 1234 行：
```js
const avatarSrc = isUser ? '/public/UserIcon.png?v=2' : '/public/AIIcon.png?v=2';
```

**`aion-chat/static/chat.html`** 第 2096 行：
```js
const avatarSrc = isUser ? '/public/UserIcon.png?v=2' : '/public/AIIcon.png?v=2';
```

**`aion-chat/static/reading.html`** 第 785、1152、1293 行：
```js
// 第785行
src="/public/AIIcon.png?v=2"
// 第1152行
const avatar = isUser ? '/public/UserIcon.png?v=2' : '/public/AIIcon.png?v=2';
// 第1293行
src="/public/AIIcon.png?v=2"
```

**`aion-chat/static/theater.html`** 第 644 行：
```js
const avatar = isUser ? '/public/UserIcon.png?v=2' : '/public/AIIcon.png?v=2';
```

**`aion-chat/static/video-call.js`** 第 75、88、176、204 行：
```js
src: '/public/视频通话背景.jpg?v=2'
src: '/public/视频来电头像.jpg?v=2'
src: '/public/视频背景照片.jpg?v=2'  // 两处
```

---

## 三、注意

- 每次换图版本号 +1，否则浏览器还是用缓存
- 换完重启服务器，普通刷新（F5）即可生效，不需要手动清浏览器缓存
